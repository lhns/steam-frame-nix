# Shiba Inu

- `model.glb`: the Shiba Inu from the
  [Ultimate Animated Animal Pack](https://quaternius.com/packs/ultimateanimatedanimals.html)
  by [Quaternius](https://quaternius.com)
- Licence: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
  (public domain; credited anyway)
- This copy: byte-identical to Poly Pizza's glb (https://poly.pizza/m/y4wdQpg767,
  https://static.poly.pizza/ba6d0ee3-bcc0-4ef0-9d3c-a3e245b41c77.glb; sha256-nL1PHhL4UCQSbqtqLFcGwJkZbfGhDbdObItnusP/9Uo=).
- Changed in steam-frame-nix (at build time, this file is unchanged): clips
  sampled per frame, poses hand-keyed, a wagging tail and breathing added,
  material colours turned into a texture (`bake_gltf.py`). The Dachshund (models/dachshund/) is this model,
  reshaped and recoloured.
